# scientific-figure

```
/plugin install scientific-figure --marketplace yangjun9095/claude-plugins
```

Build or rebuild a publication figure from whatever exists: a draft figure, a paragraph
describing what to plot, or the results section the figure has to support.

Two things make this different from drawing a chart. The figure is **generated by a script
that re-derives its numbers**, so it cannot drift from the data. And it is **reviewed by a
model that did not design it**, because a critic who shares the author's assumptions confirms
them.

## Use it with `figure-style`, not instead of it

| | `figure-style` | this plugin |
|---|---|---|
| scope | one matplotlib axes | one publication figure |
| asks | "is this plot drawn well?" | "is this file publishable, and is it true?" |
| checks | labels, spines, gridlines, font sizes, legend and colorbar overlap, text collisions, data-ink ratio | exact page width, embedded editable text, type floor, placeholder art, palette leaks, build-time data assertions, raster ppi |

Neither finds the other's defects. `scripts/style_template.py` calls `figure-style`'s
`apply_style()` first and then overrides. **Extend that plugin; do not fork it.**

## What it does

1. **Start from the claim.** Write the one sentence each panel must make a reader believe,
   before drawing. A panel with no such sentence is a panel to delete.
2. **Mine the draft before replacing it.** A hand-made draft holds finished art and settled
   decisions. Both are worth more than the drawing. `references/mining-a-draft.md` has a
   tested recipe for cutting a glyph out of a PDF while keeping it vector.
3. **Build it as a program.** One locked style module, every number re-derived from source at
   build time and asserted, one script per panel, a composer that preserves vector, and a gate
   that exits non-zero.
4. **Review with a different model.** `scripts/codex_review.sh` hands a rendered panel and its
   brief to Codex and returns a score, located issues, and a `works` list.
5. **Report what is still wrong.** A limit written down is a limit; one that is not is a claim.

## What it was built from

A Nature Methods figure rebuild. Along the way the method caught, among other things: two
panels arguing the same point with different axes, a headline claiming significance its
statistic did not support (p = 0.0038 for one test, p = 0.0723 for the one the headline also
claimed), three supplementary panels whose numbers were invented to exercise a layout, a tool
count that was wrong three different ways in one manuscript, and an image pipeline that scaled
each microscopy tile to its own range and so normalised away a six-fold difference.

Most of those were found by the second-model review, and several of the rest by assertions
that failed at build time. None was found by looking at the figure and thinking it looked fine.

## Two things that cost the most to learn

**The reviewer's findings are reliable; its diagnoses often are not.** It repeatedly named a
real defect and got the cause wrong. Fix what it SAW; argue with WHY it thinks that happened.

**Its score is noise-dominated.** Three renders differing only by a two-pixel arrow dilation
scored 82, 79 and 76. Never set a numeric pass threshold. Stop when the findings stop being
real.
