# Scientific figure

Build a figure a referee cannot misread, from whatever exists: a draft figure, a paragraph
describing what to plot, or the results section the figure has to support.

Two things make this different from drawing a chart. The figure is **generated by a script
that re-derives its numbers**, so it cannot drift from the data. And it is **reviewed by a
model that did not design it**, because a critic who shares the author's assumptions
confirms them.

---

## 0. This skill sits on top of `figure-style`. Use both.

They are different layers and neither replaces the other.

| | `figure-style` | this skill |
|---|---|---|
| scope | one matplotlib axes | one publication figure |
| gives you | `apply_style()`, `get_palette()`, `strip_embedding_axes()`, and **18 per-axes checks** | the method: claim first, mine the draft, build as a program, review with a second model |
| asks | "is this plot drawn well?" | "is this file publishable, and is it true?" |
| checks | labels, spines, gridlines, font sizes, legend and colorbar overlap, text collisions, data-ink ratio | exact page width, embedded editable text, type floor, placeholder art, palette leaks, build-time data assertions, raster ppi |

**Reach for `figure-style` alone** for a one-off plot, an exploratory figure, a slide.

**Reach for this skill** when the figure goes in a paper: when it must be reproducible from
data, must survive a referee, and must not drift from the numbers it came from.

**Wire them, do not fork them.** A project style module calls `figure-style`'s `apply_style()`
first and then overrides with what a general plotting style cannot know: exact column widths,
canonical display names, semantic colour maps kept disjoint, inch-from-top-left placement.
`scripts/style_template.py` does this. Forking instead of extending gives you two answers to
"what is the house font size" that agree only by luck, and a later improvement upstream never
reaches your figures.

Run both verifications. `figure-style`'s checks catch a badly drawn axes; `verify_figures.py`
catches an unpublishable file. Neither finds the other's defects.

## 1. What you need before you start

| Input | If you have it | If you do not |
|---|---|---|
| a draft figure | mine it: §2. Its art is an asset and its errors are findings | design from the text |
| a text description | treat each sentence as a claim the figure must support | read the results section |
| a results section | list every number the figure will show, with its source file | ask; do not invent |

**Never start by drawing.** Start by listing, for each panel, the one sentence it must make
a reader believe. A panel with no such sentence is a panel to delete.

## 2. Mine the draft before replacing it

A hand-made draft contains two things worth more than the drawing: finished art, and the
author's own decisions about what things look like.

```bash
pdfimages -list draft.pdf     # raster objects: what is a photo, what is vector
pdffonts   draft.pdf          # embedded? a missing subset changes the rendered weight
pdftotext -layout draft.pdf - # every caption and label, which is what the art MEANS
```

Then **render it and look at it**, at several resolutions. Read the PNG. Do not infer the
art from file names.

For every distinct cartoon record: what it depicts, what step it stands for, how it is
built, whether it is vector or raster, and its print ceiling if raster. See
`references/mining-a-draft.md` for the crop recipe that keeps vector, and for the traps
(art shared between two panels under two different captions; an arrow whose pixels sit
inside the block you are cropping).

**Three things a draft reliably hides, all found this way:**

- **The same art used twice under different captions.** Pixel-sample before believing a
  caption. One figure captioned identical bars "endogenous enhancers from the top DE genes"
  in one column and "sequences designed from AI models" in another.
- **A column name whose units are implicit.** `log_gap` meant ε = 0 in two files and ε = 0.1
  in a third, with nothing declaring which. Recompute from the stored inputs instead.
- **Numbering that contradicts the data.** Check the draft's own ordinals against the source
  table. Filenames inherit the draft's errors and do not encode rank.

## 3. The rules that decide what goes on the page

Grounded in Tufte. Each costs something; the cost is stated so you can overrule it.

### Data

- **Show the data when n is small.** If every observation fits legibly, draw every
  observation. A stacked bar on n = 2 draws a 50% segment that means "one". Bars are for
  when the points do not fit.
- **Drop an encoding whose information is already carried.** For each encoding ask what a
  reader could not work out without it. If "nothing", remove it, and spend the freed channel
  on something unencoded.
- **Encode the denominator when it varies.** Equal-looking marks assert equal evidence. If n
  ranges 64 to 168 across rows, n must be visible.
- **Prefer a statistic that uses the whole sample** to one that depends on a cut point,
  especially when the cut point sits inside a confidence interval. "The lowest four are all
  X" (p = 0.011, destroyed by one transposition) became a rank-sum over all items
  (p = 0.0036, survives it).

### Ink

- **The panel title states the finding, not the variable.** "Items that apply only sometimes
  agree less (rank-sum p = 0.004)", not "AC1 by item". A reader who reads only titles should
  come away with the argument.
- **Explanation lives in the caption.** *And someone must count the caption*: text stripped
  from panels reappears there unmeasured. A caption describes the **result**, never the
  rendering. If two marks cannot be separated, fix the drawing or use an SI table.
- **Quiet greys carry structure; one accent marks the argument**, and nothing else in that
  panel takes it.
- **No legend boxes. Prefer direct labelling.** Label a series beside itself in its own
  colour. A reference line carries its value as text, not a legend entry.
- **Every mark encodes something.** Erase it and ask what was lost. A full-width band
  carrying one word is the largest tone in a panel and the least information.

### Colour

- **One name per colour.** A colour that means two things is a colour the reader must
  disambiguate from context, which is the work the figure should be doing for them.
- **Declare semantic maps separately and keep them disjoint** — bases, tracks, categories,
  roles. A palette that shares hues between DNA bases and cell types makes a teal mark
  ambiguous.
- **A column may mark its own signal in its own colour; never another owner's colour.**
- **Reused finished art keeps the author's colours.** A *primitive* recomposed into a new
  glyph takes the palette of the column it now lives in.

### Type and geometry

- Lay out in **absolute inches from the top-left**; derive heights as sums, never guess.
- **Type floor**: 6 pt for anything a reader must read, 5 pt only for a unit or scale bar.
  Copy a good figure's layout, never its type sizes.
- **Never stretch art.** Change the box.

### Honesty

- **State the parameter with the number.** The same molecule reads 1.725 at ε = 0 and 1.404
  at ε = 0.1.
- **Real experimental data goes on the page as acquired.** Any adjustment must be identical
  across every tile a reader will compare, and named on the page. A per-item adjustment is
  an analysis and belongs in Methods. Per-tile scaling once normalised away a six-fold
  difference and called it display.
- **Say which denominator.** Give both when both are defensible.
- **Do not let a refusal about one instrument gag a claim about a different thing.** Check
  what a ban actually covers before applying it.

## 4. Build it as a program

Not a drawing. A program whose output is a drawing.

```
harness/
  <proj>style.py      ONE locked style: palette, semantic maps, canonical names,
                      ax_at() inch placement, tint(), save_all() -> png+pdf+svg
  <fig>data.py        every number, loaded from source and ASSERTED on each build
  panel_<key>.py      one script per panel, one function per visual block
  assemble.py         compose panel PDFs onto one page, preserving vector
  verify_figures.py   the gate; exits non-zero
  codex_review.sh     independent peer review of a rendered panel
  briefs/<key>.txt    what each panel must do, read by the reviewer
```

Copy the starting versions from `scripts/`.

**Assertions must be able to fail.** Assert *invariants* — totals reconcile, every label
resolves, coverage sums. Print *findings*. `assert set(low4) <= set(gated)` enforces a
conclusion: if the data move, the build breaks instead of the claim retiring.

**When an assert fires, fix the cause.** If a word budget blocks a word you need, cut a word
that earns less. Never raise the budget to pass.

**Turn an unavailable reuse into an assert.** If the author's art does not fit, measure why
and assert it, so that if the layout ever makes room the build fails and says to place the
art instead of drawing it.

## 5. Review with a different model

Claude reviewing a figure Claude drew confirms its own blind spots. Use `codex_review.sh`,
which hands Codex (`gpt-6-astra`) the rendered PNG plus the panel's brief and gets back a
score, a verdict, located issues, and a `works` list.

```bash
./codex_review.sh ../figures/panel_x.png briefs/x.txt    # ~90 s at effort=high
```

**Read `references/review-loop.md` before running the loop.** The essentials:

- **Findings are data; diagnoses are hypotheses.** It repeatedly names a real defect and
  misattributes the cause. Fix what it *saw*; argue with *why* it thinks that happened.
- **The score is noisy by about six points.** Three renders differing only by a two-pixel
  arrow dilation scored 82, 79, 76. It is a detector, not a scalar. **Do not set a numeric
  target and do not chase the number.** Stop when the findings stop being real.
- **Pass the `works` list to the builder** so fixes do not destroy what already works.
- **It will contradict itself across rounds.** Asked for "visibly continuous", then called
  the result "folded DNA"; asked for "one straight strip", which came out 90% paper.
- **If it flags a contradiction with the brief, suspect the brief.** One low score traced to
  an ambiguous denominator in the brief, not a defect in the panel.
- Run it at `effort=high`, not `max`: same bite, 1m32s instead of ten minutes.

## 6. Orchestration, and the way it goes wrong

Read `references/orchestration.md`. Four collisions in one session came from these:

1. **One writer per file, always.** Agents cannot see each other and neither can you:
   **workflow-internal agents do not appear in `ListAgents`.**
2. **Never message a finished agent.** A message is a *resurrection*. It revives the agent
   outside the loop's sequencing, racing whatever came next. Telling one to "stop editing"
   woke it up and it wrote more.
3. **`TaskStop` stops an agent. A message does not.** If you cannot address a workflow's
   internal agent, stop the workflow.
4. **Anchored edits only; never a whole-file write** when any concurrency is possible. An
   anchored edit fails safely; a `Write` from a stale copy silently drops the other's work.
5. **Carry findings forward to the current owner**, never back to the finished agent.

When an agent reports a collision, it is usually right. Get its measurements as *text* before
stopping it; those handovers were the most valuable artifacts produced.

## 7. Finish

1. `assemble.py` — compose, preserving vector
2. `verify_figures.py` — must pass: exact width, embedded editable text, no type under the
   floor, no placeholder or mock-up art, no colour outside the palette, every raster at or
   above 300 ppi, every data assertion holding
3. **Look at the assembled figure.** Panels can each be right and not sit together.
4. Install with provenance: a README beside the figure saying which script builds it, the
   exact rebuild commands, and that editing the PDF by hand will be lost on the next build
5. **Archive what you replace. Never overwrite hand-made work.**

**Report what is still wrong.** A limit written down is a limit; one that is not is a claim.
Separate *decisions the author must make* from *defects you could not fix*.
